# LINE APNG Studio

子どもの動画から、LINEアニメーションスタンプ用APNGを8個まとめて作るMac向けローカルツールです。

## できること

- 1本の動画から8か所を指定
- 各スタンプの開始位置、1〜4秒の長さ、構図、ズーム、文字を調整
- 64種類のオリジナル動くフレームを8カテゴリから選択
- 円、縦長、アーチ、ハート、星、吹き出し、雲、盾、四つ葉、チケット、本、テレビ、花など32種類の輪郭
- 64装飾と32輪郭を別々に選択でき、2,048通りを組み合わせ可能
- 返事、挨拶、感謝・謝罪、気持ち、家族連絡、予定・お願い、応援・労い、体調・生活を網羅
- フレーム選択時に用途に合う文言を自動入力（自由に変更可能）
- 開始位置、横位置、縦位置、ズームは最終APNGと同じ計算でプレビューへ即時反映
- サムネイル一覧と実動画プレビューの両方で動きを確認
- アプリ内の「更新を確認」から、再ダウンロードせず更新
- `01.png`〜`08.png`、`main.png`、`tab.png`、検査結果をZIP出力
- 5〜20フレーム、320×270、1MB以下を自動検査

## Macでの開始方法

1. `setup.command` をcontrolキーを押しながらクリックし、「開く」を選択（初回のみ）。
2. `start.command` を同様に開く。
3. SafariまたはChromeで `http://127.0.0.1:8765` が自動表示される。
4. 動画を選び、8個の開始位置・文字・構図を決めて生成する。

ターミナルから実行する場合：

```bash
chmod +x setup.command start.command
./setup.command
./start.command
```

## プライバシー設計

- サーバーは `127.0.0.1` にだけ接続し、同じMac以外からアクセスできません。
- 起動ごとに推測困難な専用URLを発行し、古いURLや外部ページからの操作を拒否します。
- 動画の一時領域はmacOSの非公開一時フォルダ内に作り、所有者だけが読み書きできる権限にします。
- Google Fonts、CDN、解析、広告、クラウドAPIを使いません。
- 動画処理はMac内のFFmpegとPythonで実行します。
- 元動画の一時コピーと生成途中の画像はアプリ終了時に削除し、異常終了で残ったデータも次回起動時に削除します。
- MOV/HEVCなどはMac内でブラウザ互換プレビューへ変換し、動画ファイルそのものをブラウザに直接開かせません。
- ZIPをLINE Creators Marketへ申請する操作だけは、利用者が内容を確認して手動で行います。

## 安全な自動更新

- 更新確認は、利用者が画面右上の「更新を確認」を押した時だけ行います。
- 通信先は `nafta88/line-apng-studio-updates` の固定されたGitHub配布場所だけです。
- GitHubへ送信するのはバージョン確認用の通常のHTTPリクエストだけで、動画、APNG、設定、ファイル名は送信しません。
- 更新ZIPのSHA-256とRSA電子署名を検証し、片方でも一致しなければ適用しません。
- 更新ZIPは許可済みのプログラムファイルだけを受け付け、動画、一時データ、秘密鍵、任意の実行ファイルを拒否します。
- 更新失敗時は既存プログラムを維持またはバックアップから復元します。

## 停止条件

次の場合は申請・共有せず、動画または設定を変更してください。

- 子どもの氏名、住所、制服、園名、位置情報、他人の顔などが映っている
- 本人・保護者が公開範囲に同意していない
- 自動検査がエラーを表示した
- APNGの1枚目だけを見たときに意味が伝わらない
- 生成画像に崩れ、意図しない切り取り、読めない文字がある

## LINE公式仕様への対応

2026-09-02確認時点のLINE Creators Market公式ガイドラインに合わせています。

- スタンプ画像：8個、最大320×270、APNG
- 1個：5〜20フレーム、最大4秒、1MB以下
- 再生時間：1・2・3・4秒のいずれか
- メイン画像：240×240 APNG
- タブ画像：96×74 PNG

仕様は変わる可能性があります。申請直前に以下を再確認してください。
